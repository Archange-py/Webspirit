webspirit.main module#

Module contents#

Librairie pour tout ce qui touche au web et au données que l’on peut en tirer, sous deux aspects : - L’une comme package python contenant toutes les fonctionnalité nécessaires pour le bon fonctionnement de l’application - Et l’autre comme application qui permet de récupérer les resources du web (ou de son propre ordinateur) en utilisant le package python, et de visualiser toutes les données téléchargées de manière dynamique. Il permet entre autre de gérer de manière simple et transparente ses favoris dans des collections.
